# 🌲 Лес выживание

3D-игра на выживание в браузере: добывай ресурсы, крафти, строй базу, сражайся. Есть онлайн-режим.

## Запуск
1. Установи Node.js 16+ (https://nodejs.org)
2. В папке игры: `node server.js` (или `npm start`, или двойной клик по `start.bat` / `start.sh`)
3. Открой http://localhost:3000

Порт меняется так: `PORT=8080 node server.js`.
Друзья в одной сети заходят по `http://IP-твоего-компьютера:3000`. Онлайн подключается автоматически.

## Файлы
- `index.html` — сама игра
- `server.js` — веб-сервер + онлайн (WebSocket), без зависимостей
- `package.json`, `start.bat`, `start.sh` — запуск
- `three.min.js` — скачается автоматически при первом запуске (если нет, берётся из интернета)

Сохранения хранятся в браузере игрока (localStorage).

## Что нового
- Печка как в Rust: сверху слот руды/еды, снизу слот дерева, справа готовое. Нажми «🔥 Включить» — каждые 2 сек из 1 руды/еды и 1 дерева получается 1 слиток / жареное мясо / плавленая сера. Печка работает и когда окно закрыто, содержимое сохраняется.
- Новая модель человека для других игроков: овальная голова с ушами, носом, глазами, бровями и причёской, шея, плечи, кисти, ремень, ботинки с подошвой.
- Убрана полоска HP над головой игроков (ник остался).
